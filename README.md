# Blackjack21

A multiplayer Blackjack (21) desktop game developed in Java using Swing.

## Features
- Classic Blackjack rules
- 2–4 players
- Automatic dealer
- Graphical user interface (in development)
- LAN multiplayer (planned)

## Technologies
- Java 21
- Java Swing
- TCP Sockets (planned)

## Running the Project

Compile the source files:

```bash
javac -d out src/*.java
```

Run the game:

```bash
java -cp out Main
```

## Project Status

Currently in development. Core game logic is implemented and being tested.
